## 📦 生产环境文件（必需）

这些文件是应用运行时必需的，**不能删除**。

### 核心启动文件

| 文件 | 用途 | 说明 |
|------|------|------|
| `app.py` | 主应用入口 | Flask 应用启动文件，注册所有路由，启动 Web 服务 |

### 路由模块（API 接口）

所有路由文件都是生产必需的，提供 RESTful API 接口。

| 文件 | 路由前缀 | 功能 |
|------|---------|------|
| `routes/orders.py` | `/api/orders` | 订单管理：查询、创建、修改、删除订单，Excel 导入导出 |
| `routes/products.py` | `/api/products` | 商品管理：商品 CRUD 操作 |
| `routes/customers.py` | `/api/customers` | 客户管理：客户 CRUD 操作 |
| `routes/users.py` | `/api/users` | 用户管理：登录、用户 CRUD、权限管理 |
| `routes/stores.py` | `/api/stores` | 门店管理：门店 CRUD 操作 |
| `routes/warehouses.py` | `/api/warehouses` | 仓库管理：仓库 CRUD 操作 |
| `routes/materials.py` | `/api/materials` | 物料管理：物料 CRUD 操作 |
| `routes/freight.py` | `/api/freight` | 运费管理：运费记录 CRUD 操作 |

### 工具模块

| 文件 | 用途 | 说明 |
|------|------|------|
| `utils/db.py` | 数据库连接 | 提供 `get_db()` 函数，管理 SQLite 连接 |
| `utils/db_helper.py` | 数据库操作辅助 | 核心业务逻辑，所有数据 CRUD 操作的实现 |

## 📝 文件依赖关系

### 启动流程

```
app.py (主入口 - 根目录唯一文件)
  ↓
导入 routes/*.py (所有路由)
  ↓
routes 导入 utils/db_helper.py (业务逻辑)
  ↓
db_helper.py 导入 utils/db.py (数据库连接)
  ↓
db.py 连接 data/orders.db (SQLite 数据库)
```

### 数据库初始化（仅首次或重建时）

```
tools/models.py
  ↓
init_db() 函数
  ↓
创建所有表结构
```
