# 表格布局调整：列宽、列顺序与显示隐藏

列宽拖动、表头排序和显示隐藏已合并到全局 `v-table-layout` 指令。业务组件不再需要单独导入排序弹窗、维护布局状态或改写每个数据单元格。

`v-resizable-columns` 保留为兼容别名，行为与新指令一致。当前项目中原有的 17 个可调整列宽的表格模板已经全部切换到新入口。

## 用户操作

- 拖动表头右边界：调整列宽；双击边界：恢复该列默认宽度。
- 双击表头文字或空白区域：打开“调整表格列”弹窗。
- 聚焦表头区域，按 Enter 或空格：打开列设置弹窗。
- 在弹窗中拖动列名前的图标上下排序，或使用上下箭头按钮；拖动图标也支持键盘上下键。
- 每列右侧的开关控制显示或隐藏；隐藏列仍保留在弹窗中，可随时重新开启。
- “应用设置”同步调整表头、列宽定义、数据行和合计行，隐藏列不占空间；“恢复默认”恢复默认顺序和全部显示，应用后生效。
- 至少保留一列显示；不可隐藏列的开关禁用。
- 取消、关闭、Esc 或点击遮罩不修改顺序和显示状态。多选框列自动固定在最左侧。
- 表头中的复选框、输入框、下拉框和列宽调整边界不会打开排序弹窗。

为区分单击数据排序和双击布局排序，表头上的鼠标单击会延迟 500ms 执行；双击取消这次单击。键盘触发的按钮点击及表格正文操作不延迟。

## 最简接入

```vue
<template>
  <div class="table-scroll">
    <table v-table-layout="{ storageKey: 'product-list', resizeMode: 'fit', minWidth: 64 }">
      <colgroup>
        <col data-column-key="name" style="width: 180px">
        <col data-column-key="stock" style="width: 100px">
        <col data-column-key="actions" style="width: 100px">
      </colgroup>
      <thead>
        <tr>
          <th data-column-key="name">商品名称</th>
          <th data-column-key="stock">库存</th>
          <th data-column-key="actions" data-resizable="false">操作</th>
        </tr>
      </thead>
      <tbody>
        <tr v-for="row in records" :key="row.id">
          <td>{{ row.name }}</td>
          <td>{{ row.stock }}</td>
          <td><button type="button" @click="openDetail(row)">查看</button></td>
        </tr>
        <tr v-if="!records.length"><td colspan="3">暂无数据</td></tr>
      </tbody>
    </table>
  </div>
</template>

<style scoped>
.table-scroll { overflow-x: auto; }
table { width: 100%; table-layout: fixed; border-collapse: collapse; }
</style>
```

指令和样式在 `src/main.js` 中统一注册。业务模板中的每列必须有一个 `<col>`，表头只能有一行，且表头不能包含合并单元格。原有业务模板继续按默认列顺序书写，用户隐藏由指令统一处理。

不要再为同一张表额外绑定 `openColumnOrder` 或挂载一个排序弹窗。已有数据驱动排序的特殊表格若需保留自己的弹窗，应传入 `reorder: false`，只复用列宽能力。

## 选项

| 选项 | 默认值 | 说明 |
| --- | --- | --- |
| `enabled` | `true` | `false` 禁用列宽、排序与显示隐藏；直接绑定 `false` 效果相同 |
| `reorder` | `true` | `false` 关闭公共列设置（排序与显示隐藏），保留列宽调整 |
| `storageKey` | `''` | 表格独立标识；省略时偏好仅保留到该表格卸载 |
| `resizeMode` | `'expand'` | `'fit'` 保持表格总宽度，由另一可调整列补偿；`'expand'` 允许总宽度改变 |
| `minWidth` | `40` | 默认最小列宽，单位 px |
| `maxWidth` | 无限制 | 默认最大列宽，单位 px |
| `onResize` | 无 | 列宽操作完成时收到 `{ key, index, width, widths }` |
| `onReorder` | 无 | 应用设置后收到 `{ keys, hiddenKeys }`；`keys` 包含当前业务列的完整顺序，`hiddenKeys` 是其中被用户隐藏的列 |

也支持字符串简写：`v-table-layout="'product-list'"`。

## 列属性

属性可放在 `<th>` 或对应的 `<col>`：

| 属性 | 说明 |
| --- | --- |
| `data-column-key` | 稳定、唯一的列标识，同时用于宽度与顺序保存；未设置时兼容原有规范化表头文字 |
| `data-min-width` / `data-max-width` | 当前列的宽度限制，优先于全局选项 |
| `data-resizable="false"` | 不允许调整宽度，也不参与宽度补偿；仍可改变顺序 |
| `data-column-fixed="start"` | 排序固定在最左侧 |
| `data-column-fixed="end"` | 排序固定在最右侧 |
| `data-column-hideable="false"` | 此列必须显示；固定位置与是否可隐藏相互独立 |

表头含多选复选框时自动固定在左侧，无需额外声明。其它固定列请显式设置 `data-column-fixed`。

库存列表、采购主列表和采购退货列表原有的右侧吸附操作列已显式固定在最右侧，避免横向滚动时与调整后的普通列重叠。未吸附的操作列可以正常排序。

新增页面优先为每列指定稳定 key。动态税列、权限列和业务模式可以条件渲染，只需保证表头、colgroup 与正文中的可见列对应。

## 合计、跨行与 Vue 更新

- 合计行的 `colspan` 按原本覆盖的业务列映射。排序使其分散时，拆成连续片段，业务内容只显示一次，其余片段为空；数值始终跟随所属列。
- 全宽加载行和空态行继续占满表格，不会被拆成多份内容。
- 隐藏列的表头、col 和对应数据单元格暂时从表格中移除，合计 `colspan` 按实际可见列重算；重新显示时复用原节点及当前业务值。
- `rowspan` 按每个 `tbody` 的逻辑网格计算，支持入库批次表一批多商品、日期/仓库/状态跨行的布局。
- 业务输入框、按钮和 Vue 节点复用，不复制业务内容；调整和数据刷新时保留编辑焦点与支持的文本选区。
- 指令在 Vue `beforeUpdate` 阶段还原源码顺序及循环锚点，`updated` 后重新应用布局；卸载时也先还原，避免影响 Vue 更新。
- 多行表头、多个 colgroup、列数不匹配或重叠合并网格不启用列排序，不猜测业务列关系。

业务样式优先使用列 class 或 `[data-column-key="..."]`，避免让 `nth-child()` 的样式随视觉位置转移。现有接入表格的旧位置样式已做兼容：指令提供从 1 开始的 `data-layout-column-index` 和 `data-layout-column-end-index`，表示默认业务列位置。

## 保存与兼容

- 列宽仍使用 `table-column-widths:<storageKey>`，顺序使用 `table-column-order:<storageKey>`，沿用旧保存格式。
- 显示开关使用 `table-column-hidden:<storageKey>` 保存隐藏 key 数组；未保存时全部显示，隐藏操作不清空原有列宽或排序。
- 原有销售财务/物流列表的已保存顺序、所有表格的已保存列宽可继续读取。
- 各业务模式沿用各自的 storageKey，不覆盖其它表格的偏好。
- 隐藏列的已保存位置保留；列重新出现时恢复。删除的列不显示，新增列追加，固定列仍位于指定一端。
- 无效 JSON 或存储不可用时使用默认布局；保存失败仍可在当前表格中操作。
- 仅保存浏览器偏好，不修改业务数据、后端接口或 Excel 导出的业务列顺序。
