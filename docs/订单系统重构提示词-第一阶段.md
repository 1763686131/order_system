## 步骤 2：创建后端保存接口

### 任务描述
请帮我在后端创建一个保存订单的 API 接口，路径为 `POST /api/orders`。

### 接口要求
1. **接收参数**：前端 OrderForm.vue 的 formData
2. **数据处理**：
   - 生成订单ID（自增）
   - 生成订单编号（如果前端没传）：`ZG + YYYYMMDD + 三位ID`
   - 填充新旧两套字段
   - 计算财务字段（小计、税额、应收等）
   - 设置订单状态为 `completed`（已完成）
   - 设置 `type = 1`（新订单标识）
3. **库存扣减**：遍历 `order_goods`，从对应仓库扣减库存
4. **保存到文件**：`data/orders_db.json`
5. **返回结果**：
   ```json
   {
     "success": true,
     "message": "订单保存成功",
     "orderId": 123,
     "orderNumber": "ZG20260902123"
   }
   ```

### 注意事项
- 库存不足时返回错误信息，不保存订单
- 需要事务性：要么全部成功，要么全部回滚
- 保存时间字段：`date` = 订单日期，`completed_date` = 当前时间

### 参考文件
- 后端路由文件：`backend/routes/orders.py`
- 数据库操作：`backend/utils/db_helper.py`
- 库存扣减逻辑：参考现有的 `update_stock` 函数

## 步骤 3：前端对接保存接口

### 任务描述
请帮我在 `OrderForm.vue` 中实现保存订单的功能。

### 功能点
1. **表单校验**：
   - 门店、客户、仓库必选
   - 至少有一条商品明细
   - 商品的件数、数量、单价必填
   - 联系人、联系方式必填

2. **保存逻辑**：
   ```javascript
   const handleSave = async (printAfterSave = false) => {
     // 1. 校验表单
     if (!validateForm()) return
     
     // 2. 构建请求数据
     const requestData = {
       storeId: formData.value.storeId,
       customerId: formData.value.customerId,
       warehouseId: formData.value.warehouseId,
       orderDate: formData.value.orderDate,
       orderNumber: formData.value.orderNumber,
       contactPerson: formData.value.contactPerson,
       contactPhone: formData.value.contactPhone,
       contactAddress: formData.value.contactAddress,
       projectName: formData.value.projectName,
       salesPerson: formData.value.salesPerson,
       creator: formData.value.creator,
       orderRemark: formData.value.orderRemark,
       taxRate: formData.value.taxRate,
       discountAmount: formData.value.discountAmount || 0,
       otherFees: formData.value.otherFees || 0,
       settlementAccount: formData.value.settlementAccount,
       currentPayment: formData.value.currentPayment || 0,
       items: formData.value.items.map(item => ({
         productId: item.productId,
         goodsName: item.goodsName,
         spec: item.spec,
         unit: item.unit,
         warehouseId: item.warehouseId,
         packages: item.packages,
         quantity: item.quantity,
         price: item.price,
         taxRate: item.taxRate,
         taxIncludedPrice: item.taxIncludedPrice,
         amount: item.amount,
         totalAmount: item.totalAmount,
         remark: item.remark
       }))
     }
     
     // 3. 调用接口
     const response = await request({
       url: '/orders',
       method: 'POST',
       data: requestData
     })
     
     // 4. 处理结果
     if (response.success) {
       alert('订单保存成功！')
       if (printAfterSave) {
         // TODO: 打印逻辑
       }
       handleClose() // 关闭窗口
     }
   }
   ```

3. **按钮绑定**：
   - "保存后打印" 按钮：`@click="handleSave(true)"`
   - "保存并打印" 按钮：`@click="handleSave(true)"`
   - "保存" 按钮：`@click="handleSave(false)"`

## 关键注意事项

### ⚠️ 数据一致性
- 新订单必须同时填充新旧字段
- 旧字段作为冗余，方便其他页面查询
- 不要删除旧字段，保证向后兼容

### ⚠️ 库存扣减
- 必须在保存订单的同时扣减库存
- 库存不足时整个订单都不保存
- 扣减时使用 `order_goods` 中的 `quantity`（不是 `packages`）

### ⚠️ 类型标识
- 新订单设置 `type = 1`
- 旧订单保持 `type = 0`
- 其他页面可以根据 `type` 或 `order_goods` 是否存在来判断

### ⚠️ 字段映射
- `goods_name` 的拼接格式要清晰
- `goods_weight` 和 `goods_quantity` 要带单位
- 客户名称从 customers 表查询，不是前端传的
