# 商品名称显示问题修复总结

## 🐛 问题描述

**现象**：商品明细弹窗可以正常打开，但是商品名称列显示为空（`-`）

**影响**：无法看到订单中具体是什么商品

---

## 🔍 问题分析

### 根本原因

订单数据中的 `goods_name` 字段为**空字符串**：

```json
{
  "order_goods": [
    {
      "product_id": 2,
      "goods_name": "",  // ❌ 空字符串
      "spec": "1101A",
      "unit": "公斤",
      "quantity": 500,
      "price": 50
    }
  ]
}
```

### 为什么 goods_name 是空的？

**字段名不匹配**导致的：

1. **OrderForm.vue**（订单录入页面）：
   - 选择商品时设置的字段名：`item.productName`
   - 保存时使用的字段名：`item.goodsName`
   - 结果：`item.goodsName` 未定义，保存为空字符串

2. **代码片段**：

```javascript
// OrderForm.vue - 选择商品时（第 482 行）
const selectProduct = (index, product) => {
  item.productName = product.name  // ✅ 设置了 productName
  // ❌ 但是没有设置 goodsName
}

// OrderForm.vue - 保存时（第 807 行）
items: validItems.map(item => ({
  goodsName: item.goodsName,  // ❌ 读取的是 goodsName（未定义）
  // ...
}))
```

---

## ✅ 修复方案

### 方案概述

采用**双重修复**策略：
1. **修复前端**：避免以后再保存空的商品名称
2. **修复展示**：兼容已保存的空商品名称数据

---

### 修复 1：OrderForm.vue - 保存时填充 goodsName

**文件**：`src/views/admin/orders/OrderForm.vue`

**位置**：第 479-484 行

**修改前**：
```javascript
const selectProduct = (index, product) => {
  const item = formData.value.items[index]
  item.productId = product.id
  item.productName = product.name
  item.spec = product.specification || ''
  // ...
}
```

**修改后**：
```javascript
const selectProduct = (index, product) => {
  const item = formData.value.items[index]
  item.productId = product.id
  item.productName = product.name
  item.goodsName = product.name  // ✅ 添加这行
  item.spec = product.specification || ''
  // ...
}
```

**效果**：以后保存的订单会包含正确的商品名称

### 修复 2：UnifiedOrderList.vue - 显示时反查商品名称

**文件**：`src/views/admin/orders/UnifiedOrderList.vue`

#### 修改 A：添加商品列表数据

**位置**：第 590-594 行

```javascript

const orders = ref([])
const loading = ref(false)
```

#### 修改 B：添加反查函数

**位置**：约第 1010 行（`isNewOrder` 函数之后）

```javascript
// 根据 product_id 查找商品名称
const getProductNameById = (productId) => {
  if (!productId) return '-'
  const product = products.value.find(p => p.id === productId)
  return product ? product.name : `商品#${productId}`
}

// 获取商品明细的商品名称（兼容空 goods_name）
const getGoodsItemName = (item) => {
  // 1. 优先使用 goods_name
  if (item.goods_name && item.goods_name.trim()) {
    return item.goods_name
  }
  // 2. 回退到通过 product_id 查找
  if (item.product_id) {
    return getProductNameById(item.product_id)
  }
  // 3. 都没有，返回默认值
  return '-'
}
```

#### 修改 C：加载商品数据

**位置**：`fetchOrdersData` 函数（约第 813 行）

**修改前**：
```javascript
const fetchOrdersData = async () => {
  loading.value = true
  try {
    // 并行加载订单和门店数据
    const [ordersResponse, storesData] = await Promise.all([
      request({ url: '/orders', method: 'GET' }),
```

**修改后**：
```javascript
const fetchOrdersData = async () => {
  loading.value = true
  try {
    // 并行加载订单、门店和商品数据
    const [ordersResponse, storesData, productsData] = await Promise.all([
      request({ url: '/orders', method: 'GET' }),
      getStores(),
      request({ url: '/products/inventory', method: 'GET' })  // ✅ 添加商品加载
    ])
    
    // ...
    
    // 保存商品列表
    if (productsData && Array.isArray(productsData)) {
      products.value = productsData
    }
```

#### 修改 D：弹窗模板使用新函数

**位置**：弹窗商品明细表格（约第 449 行）

**修改前**：
```html
<td>{{ item.goods_name || '-' }}</td>
```

**修改后**：
```html

```

**效果**：
- 如果 `goods_name` 有值，显示 `goods_name`
- 如果 `goods_name` 为空，通过 `product_id` 查找商品名称
- 如果都没有，显示 `-`

## 💡 经验总结

### 1. 字段命名要统一

**问题**：
- 前端使用 `productName`
- 后端期望 `goodsName`
- 导致数据丢失

**教训**：
- ✅ 字段名应该在前后端保持一致
- ✅ 保存前应该验证必填字段
- ✅ 使用 TypeScript 可以避免这类问题

### 2. 数据展示要兼容历史数据

**问题**：
- 已保存的数据 `goods_name` 为空
- 新代码无法处理

**教训**：
- ✅ 显示数据时要有回退方案
- ✅ 通过关联 ID 可以恢复缺失的数据
- ✅ 兼容性优先

### 3. 数据冗余的价值

**现状**：
- 保存了 `product_id`（关联）
- 也保存了 `goods_name`（冗余）

**好处**：
- ✅ 即使商品被删除，订单仍能显示商品名称
- ✅ 查询效率高（不需要 JOIN）
- ✅ 历史快照准确
