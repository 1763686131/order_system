## 📊 数据结构变化

### 新增字段（保存到 orders_db.json）

**基础信息**：
- `customer_id` - 客户ID
- `warehouse_id` - 仓库ID
- `order_number` - 订单编号（ZG20260904001）
- `contact_person` - 联系人
- `project_name` - 工程项目

**商品明细**：
- `order_goods` - 商品明细数组（核心！）
  - 包含：商品ID、名称、规格、单位、数量、单价、税率等

**财务信息**：
- `subtotal_amount` - 小计（不含税）
- `tax_amount` - 税额
- `total_amount` - 价税合计
- `discount_amount` - 折扣金额
- `should_receive` - 本单应收
- `current_payment` - 本次收款
- `current_debt` - 本单欠款

### 保留字段（向后兼容）
旧字段全部保留，自动从新字段映射填充：
- `order_client` ← 客户名称
- `receiver_name` ← 联系人
- `goods_name` ← 商品拼接字符串
- `goods_weight` ← 总数量+单位
- `goods_quantity` ← 总件数

## ⚠️ 重要提示

### 1. 向后兼容
新订单不会影响旧页面的显示，因为保留了所有旧字段。

### 2. 类型标识
- 新订单：`type = 1`
- 旧订单：`type = 0`

### 3. 库存扣减
使用 `quantity`（数量），不是 `packages`（件数）。

### 4. 备份建议
测试前建议备份数据文件：
```bash
cp data/orders_db.json data/orders_db.json.backup
cp data/products_db.json data/products_db.json.backup
```

## 🐛 常见问题

**Q: 保存失败，提示"库存不足"？**
A: 打开 `data/products_db.json`，增加对应商品的 `stock` 值。

**Q: 商品下拉框不显示？**
A: 先选择门店和仓库，再点击商品输入框。

**Q: 保存成功但没看到订单编号？**
A: 检查浏览器是否拦截了 alert，或查看浏览器控制台。

**Q: 旧页面看不到新订单？**
A: 新订单应该能正常显示，因为旧字段都已填充。如果看不到，请检查订单状态过滤。
