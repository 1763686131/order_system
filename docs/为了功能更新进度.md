# 订单系统功能更新进度

## 开发策略

**采用垂直切片开发**：按模块逐个完成前后端，每完成一个模块立即联调测试。

### 开发顺序

#### 阶段一：基础数据模块
1. **原材料模块**（后端 → 前端）
   - 独立模块，无复杂依赖
   - 为库存和出库单提供基础数据

2. **库存模块**（后端 → 前端）
   - 依赖商品数据
   - 为出库单提供库存查询

#### 阶段二：核心业务模块
3. **应收欠款模块**（后端 → 前端）
   - 先完成表结构和基础 CRUD
   - 为出库单和收款单提供关联基础

4. **出库单模块**（后端 → 前端）⭐ 核心模块
   - 系统主线业务流程
   - 关联：客户（✅已完成）+ 商品 + 应收欠款
   - 重点测试数据联动逻辑

#### 阶段三：财务模块
5. **收款单模块**（后端 → 前端）
   - 依赖应收欠款
   - 实现金额冲销逻辑

6. **库存管理模块**（后端 → 前端）
   - 直接操作库存调整
   - 需要权限控制和操作日志

### 单模块开发流程
```
数据库表设计 → 后端接口 → 接口测试 → 前端页面 → 联调测试
```
