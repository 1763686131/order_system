### BUG修复与优化 ✅ 已完成（2026-09-05）
1. **统一新增订单按钮**

   - 保留 Admin.vue 顶部的"录入订单"按钮作为唯一入口

2. **动态菜单标题**
   - 新增订单时显示："订单/新增订单"
   - 编辑订单时显示："订单/修改订单"
   - 通过路由监听和 meta 标题动态更新

3. **订单编号优化**
   - 修改格式：ZG20260905001（最后3位是订单ID）

   - 编辑时保持原订单编号不变

4. **表单字段优化**
   - 件数、单价改为选填（不再必填）
   - 保存订单时默认状态改为"未完成"（null）
   - 业务员默认值改为"柯晓"
   - 制单人默认值改为"下单员"

5. **编辑模式表格优化**
   - 编辑订单时，表格显示"数据行数 + 3 行空行"
   - 避免表格过于紧凑，提升编辑体验

6. **自定义保存弹窗**
   - 替换所有浏览器 alert 为自定义弹窗
   - 成功弹窗：绿色圆形图标 + ✓
   - 失败弹窗：红色圆形图标 + ✕
   - z-index: 99999 确保弹窗始终在最上层
   - 支持换行显示订单编号等信息

## 开发策略

**采用垂直切片开发**：按模块逐个完成前后端，每完成一个模块立即联调测试。

### 开发顺序

#### 阶段一：基础数据模块 ✅ 已完成
1. **库存模块**（后端 → 前端）✅
   - 依赖商品数据
   - 为出库单提供库存查询
   - v2.91-v2.92 已实现

2. **客户管理模块**（后端 → 前端）✅
   - 独立模块，为订单提供客户数据
   - v2.93-v2.94 已实现

#### 阶段二：核心业务模块 🔄 进行中
3. **订单录入模块**（后端 → 前端）✅
   - 系统主线业务流程
   - 关联：客户（✅已完成）+ 商品
   - v2.95-v2.98 已实现基础功能

4. **原材料模块**（后端 → 前端）⏳
   - 独立模块，无复杂依赖
   - 为库存和出库单提供基础数据

5. **应收欠款模块**（后端 → 前端）⏳
   - 先完成表结构和基础 CRUD
   - 为出库单和收款单提供关联基础

#### 阶段三：财务模块 ⏳ 待开发
6. **收款单模块**（后端 → 前端）
   - 依赖应收欠款
   - 实现金额冲销逻辑

7. **库存调整模块**（后端 → 前端）
   - 直接操作库存调整
   - 需要权限控制和操作日志

### 单模块开发流程
```
数据库表设计 → 后端接口 → 接口测试 → 前端页面 → 联调测试
```
