## 开发策略

**采用垂直切片开发**：按模块逐个完成前后端，每完成一个模块立即联调测试。

### 开发顺序

#### 阶段一：基础数据模块 ✅ 已完成
1. **库存模块**（后端 → 前端）✅
   - 依赖商品数据
   - 为出库单提供库存查询
   - v2.91-v2.92 已实现

2. **客户管理模块**（后端 → 前端）✅
   - 独立模块，为订单提供客户数据
   - v2.93-v2.94 已实现

#### 阶段二：核心业务模块 🔄 进行中
3. **订单录入模块**（后端 → 前端）✅
   - 系统主线业务流程
   - 关联：客户（✅已完成）+ 商品
   - v2.95-v2.98 已实现基础功能

4. **原材料模块**（后端 → 前端）⏳
   - 独立模块，无复杂依赖
   - 为库存和出库单提供基础数据

5. **应收欠款模块**（后端 → 前端）⏳
   - 先完成表结构和基础 CRUD
   - 为出库单和收款单提供关联基础

#### 阶段三：财务模块 ⏳ 待开发
6. **收款单模块**（后端 → 前端）
   - 依赖应收欠款
   - 实现金额冲销逻辑

7. **库存调整模块**（后端 → 前端）
   - 直接操作库存调整
   - 需要权限控制和操作日志

### 单模块开发流程
```
数据库表设计 → 后端接口 → 接口测试 → 前端页面 → 联调测试
```
