# 本单应收

## 🔑 关键技术点

### 1. 事务性保证

**问题**：库存扣减和订单保存必须同时成功或同时失败

**解决方案**：
- 使用线程锁（orders_lock）防止并发冲突
- 先检查所有商品库存，全部通过后再扣减
- 使用临时文件写入（.tmp）+ 原子替换（os.replace）

```python
with orders_lock:
    # 1. 检查库存
    for item in items:
        if stock < quantity:
            return error  # 任何一个不满足，直接返回

    # 2. 扣减库存
    for product in products:
        product['stock'] -= quantity

    # 3. 保存订单和库存
    write_orders(orders_data)
    write_products(products_data)
```

### 2. 新旧字段映射

**问题**：如何保证旧字段与新字段数据一致

**解决方案**：
- 新字段为主数据源
- 旧字段从新字段计算得出
- 使用明确的映射函数

```python
# goods_name 拼接
goods_name_parts = []
for item in order_goods:
    goods_name_parts.append(f"{item['goods_name']} {item['spec']} x{item['quantity']}")
goods_name = '、'.join(goods_name_parts)

# goods_weight 计算
total_quantity = sum(item['quantity'] for item in order_goods)
goods_weight = f"{total_quantity}{first_unit}"

# goods_quantity 计算
total_packages = sum(item['packages'] for item in order_goods)
goods_quantity = f"{total_packages}件"
```

## ⚠️ 注意事项

### 1. 数据一致性

**必须同时填充新旧字段**
- 新订单：`type = 1`
- 旧订单：`type = 0`
- 判断依据：`type` 或 `order_goods` 是否存在

### 2. 库存扣减

**使用 quantity（数量），不是 packages（件数）**
```python
# ✅ 正确
product['stock'] -= item['quantity']

# ❌ 错误
product['stock'] -= item['packages']
```

### 3. 财务计算

**单价必须是不含税单价**
```javascript
// 前端输入
price: 50  // 不含税单价
taxRate: 13

// 自动计算
taxIncludedPrice: 50 × 1.13 = 56.50
amount: quantity × price
totalAmount: quantity × taxIncludedPrice
```

### 4. 字段映射

**客户名称从数据库查询，不是前端传递**
```python
# ✅ 正确
customer = find_customer_by_id(customer_id)
order_client = customer['customerName']

# ❌ 错误
order_client = req_data.get('customerName')
```
