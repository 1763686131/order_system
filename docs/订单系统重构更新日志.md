**关键代码**：
```javascript
const handleSave = async (printAfterSave = false) => {
  if (!validateForm()) return
  if (saving.value) return
  
  try {
    saving.value = true
    const response = await request({
      url: '/orders',
      method: 'POST',
      data: requestData
    })
    
    if (response && response.success) {
      alert(`订单保存成功！\n订单编号：${response.orderNumber}`)
      handleClose()
    }
  } catch (error) {
    alert('保存失败：' + error.message)
  } finally {
    saving.value = false
  }
}
```

### 🔑 核心特性

#### 1. 新旧字段并存
```json
{
  "旧字段": {
    "order_client": "锦州森源",
    "receiver_name": "张三",
    "goods_name": "碳纤维胶 5kg x10、灌注胶 10kg x5",
    "goods_weight": "15kg",
    "goods_quantity": "3件"
  },
  "新字段": {
    "customer_id": 1,
    "order_number": "ZG20260904001",
    "order_goods": [...],
    "subtotal_amount": 1000.00,
    "tax_amount": 130.00
  }
}
```

#### 2. 自动字段映射
- `order_client` ← 通过 `customer_id` 查询客户名称
- `receiver_name` ← `contact_person`
- `goods_name` ← 所有商品拼接
- `goods_weight` ← 总数量 + 单位
- `goods_quantity` ← 总件数 + "件"

#### 3. 库存管理
- 保存前检查所有商品库存
- 库存不足时阻止保存并提示
- 保存成功后自动扣减库存
- 使用线程锁保证并发安全

#### 4. 财务计算
```
小计 = Σ(商品数量 × 单价)
税额 = Σ(含税金额 - 不含税金额)
价税合计 = 小计 + 税额
本单应收 = 折扣金额 + 其他费用
本单欠款 = 本单应收 - 本次收款
```

#### 5. 订单编号
- 格式：`ZG + YYYYMMDD + 三位ID`
- 示例：`ZG20260904001`
- 前端未填写时自动生成

### 🐛 修复的问题

#### 1. 库存扣减不准确
**问题**：旧版本没有实时扣减库存
**解决**：新版本保存订单时同步扣减库存

#### 2. 财务计算不透明
**问题**：旧版本没有记录税额、小计等详细信息
**解决**：新版本保存所有财务计算字段

#### 3. 单商品限制
**问题**：旧版本只能保存单个商品的文本描述
**解决**：新版本支持多商品明细数组

#### 4. 缺少表单校验
**问题**：旧版本可以保存空订单
**解决**：新版本有完整的表单校验

### ⚠️ 重要注意事项

#### 1. 向后兼容
- 旧格式订单仍然可以正常保存（`type = 0`）
- 新格式订单标记为 `type = 1`
- 旧页面可以继续读取新订单的旧字段

#### 2. 数据一致性
- 新订单必须同时填充新旧两套字段
- 旧字段作为冗余，方便查询和展示
- 不要删除旧字段

#### 3. 库存扣减
- 使用 `quantity`（数量）扣减，不是 `packages`（件数）
- 库存不足时整个订单不保存
- 使用线程锁防止并发冲突

#### 4. 类型标识
- 新订单：`type = 1`
- 旧订单：`type = 0`
- 可通过 `type` 或 `order_goods` 是否存在判断

### 🚀 性能优化

1. **减少数据库读取次数**
   - 一次读取所有需要的数据（客户、门店、商品）
   - 使用内存缓存避免重复查询

2. **使用原子操作**
   - 使用 `os.replace()` 替换文件，保证原子性
   - 使用线程锁防止并发写入冲突

3. **批量处理**
   - 一次性检查所有商品库存
   - 一次性扣减所有商品库存
