# 库存相关问题修复总结

## 🐛 发现的问题

### 问题 1：库存不显示
**现象**：订单录入页面选择商品后，"当前库存"列显示为空

**原因**：
- 库存数据存储在 `products_db.json` 的 `inventory` 对象中
- 前端调用的 `/api/products` 接口不包含库存信息

**修复**：✅ 已完成
- 修改前端接口为 `/api/products/inventory`

---

### 问题 2：库存检查阻止保存
**现象**：提交订单时提示"库存不足"，无法保存

**原因**：
- 后端会检查库存是否充足
- 库存不足时阻止订单保存

**修复**：✅ 已完成
- 移除库存检查逻辑
- 允许负库存

---

### 问题 3：库存扣减位置错误
**现象**：保存订单后库存没有正确扣减

**原因**：
- 代码尝试从 `products` 数组的 `stock` 字段扣减
- 但实际库存在 `inventory` 对象中

**修复**：✅ 已完成
- 修改为从 `inventory` 对象中扣减库存

---

### 2. 后端修改

**文件**：`backend/routes/orders.py`

#### 修改 A：移除库存检查（允许负库存）

**修改前**：
```python
# 检查库存
current_stock = product.get('stock', 0)
if current_stock < quantity:
    return jsonify({
        "success": False,
        "message": f"商品库存不足！"
    }), 400
```

**修改后**：
```python
# 不检查库存，允许负库存
```

#### 修改 B：修复库存扣减逻辑

**修改前**：
```python
# 扣减库存
for item in items:
    for product in products_list:
        if product['id'] == product_id:
            product['stock'] = product.get('stock', 0) - quantity
            break
```

**修改后**：
```python
# 扣减库存（从 inventory 对象中扣减）
if 'inventory' not in products_data:
    products_data['inventory'] = {}

inventory_list = products_data['inventory']

for item in items:
    product_id = item.get('productId')
    quantity = item.get('quantity', 0)
    
    if not product_id or not quantity:
        continue
    
    product_id_str = str(product_id)
    
    # 如果 inventory 中没有该商品记录，初始化为0
    if product_id_str not in inventory_list:
        inventory_list[product_id_str] = {
            'stock': 0,
            'minStock': 0,
            'maxStock': 0,
            'updatedAt': datetime.now().strftime('%Y-%m-%d %H:%M:%S')
        }
    
    # 扣减库存（允许负数）
    current_stock = inventory_list[product_id_str].get('stock', 0)
    inventory_list[product_id_str]['stock'] = current_stock - quantity
    inventory_list[product_id_str]['updatedAt'] = datetime.now().strftime('%Y-%m-%d %H:%M:%S')

products_data['inventory'] = inventory_list
```

## 💡 关键要点

### 1. 库存存储位置
```json
{
  "products": [
    { "id": 1, "name": "商品A" }
    // 注意：这里没有 stock 字段
  ],
  "inventory": {
    "1": { 
      "stock": 4000  // ← 库存在这里
    }
  }
}
```

### 2. 获取带库存的商品列表
```javascript
// ✅ 正确
GET /api/products/inventory

// ❌ 错误（不包含库存）
GET /api/products
```

### 3. 扣减库存
```python
# ✅ 正确
inventory["1"]["stock"] -= quantity

# ❌ 错误
products[0]["stock"] -= quantity
```

### 4. 允许负库存
- 不检查库存是否充足
- 直接扣减，允许结果为负数
- 业务上可以理解为"欠货"或"预售"

---

## ⚠️ 注意事项

### 1. 负库存的业务含义
- 负库存表示"欠货"
- 需要后续补充库存
- 可能需要在界面上特殊标识

### 2. 库存数据类型
- `inventory` 的 key 是字符串类型的商品ID
- 例如：`"1"`、`"2"`，不是 `1`、`2`

### 3. 库存初始化
- 如果商品在 `inventory` 中没有记录，默认为 0
- 扣减后会自动创建记录
