# 商品表单字段说明

## products_db.json 产品表单字段说明说明


## 基本信息 (submitData)

### 必填字段

| 字段名 | 类型 | 中文说明 | 备注 |
|--------|------|----------|------|
| `storeIds` | Array | 门店ID列表 | 商品所属的门店，支持多选 |
| `warehouseId` | Number | 仓库ID | 商品的默认仓库 |
| `categoryId` | Number | 分类ID | 商品所属的仓库分类 |
| `name` | String | 商品名称 | 商品的名称 |
| `unitId` | Number | 基础单位ID | 商品的基础计量单位 |

### 可选字段

| 字段名 | 类型 | 中文说明 | 备注 |
|--------|------|----------|------|
| `code` | String | 商品编号 | 商品的编号/货号 |
| `specification` | String | 规格型号 | 商品的规格型号描述 |
| `notes` | String | 备注信息 | 商品的备注说明 |
| `enabled` | Boolean | 启用状态 | 商品是否启用，默认为 true |

## 单位换算 (unitConversions)

多单位换算关系数组，每个元素包含：

| 字段名 | 类型 | 中文说明 | 备注 |
|--------|------|----------|------|
| `fromUnitId` | Number | 换算单位ID | 需要转换的单位 |
| `value` | Number | 换算值 | 1个 fromUnit = value 个 baseUnit |
| `splits` | Array | 分裂项数组 | 该单位可分裂成的其他单位 |

### 分裂项 (splits)

每个分裂项包含：

| 字段名 | 类型 | 中文说明 | 备注 |
|--------|------|----------|------|
| `quantity` | Number | 数量 | 分裂后的数量 |
| `unitId` | Number | 单位ID | 分裂后的单位 |

**示例：**
```json
{
  "fromUnitId": 2,  // 箱
  "value": 10,      // 1箱 = 10个基础单位
  "splits": [
    {
      "quantity": 5,  // 1箱可以分裂成5包
      "unitId": 3
    }
  ]
}
```

## 属性相关 (enableAttributes 为 true 时)

### 属性启用

| 字段名 | 类型 | 中文说明 | 备注 |
|--------|------|----------|------|
| `enableAttributes` | Boolean | 是否启用属性 | 是否为商品设置多规格属性 |

### 属性组合 (attributeCombinations)

当启用属性时，包含属性组合数组，每个组合包含：

| 字段名 | 类型 | 中文说明 | 备注 |
|--------|------|----------|------|
| `id` | Number | 组合索引 | 属性组合的索引编号 |
| `name` | String | 组合名称 | 属性组合的显示名称，如 "红色 / L码" |
| `purchasePrice` | Number | 进货价 | 该属性组合的进货价格 |
| `wholesalePrice` | Number | 批发价 | 该属性组合的批发价格 |
| `retailPrice` | Number | 零售价 | 该属性组合的零售价格 |
| `barcode` | String | 条形码 | 该属性组合的条形码 |
| `enabled` | Boolean | 启用状态 | 该属性组合是否启用 |

**示例：**
```json
{
  "id": 0,
  "name": "红色 / L码",
  "purchasePrice": 50,
  "wholesalePrice": 80,
  "retailPrice": 100,
  "barcode": "6901234567890",
  "enabled": true
}
```

## 完整提交数据示例

```json
{
  "storeIds": [1, 2],              // 选中的门店：绝缘、中固
  "warehouseId": 1,                 // 仓库ID
  "categoryId": 101,                // 分类ID
  "name": "绝缘胶",                 // 商品名称
  "code": "001",                    // 商品编号
  "specification": "01",            // 规格型号
  "notes": "测试备注",              // 备注
  "unitId": 1,                      // 基础单位：公斤
  "enabled": true,                  // 启用状态
  "unitConversions": [              // 单位换算
    {
      "fromUnitId": 2,              // 箱
      "value": 10,                  // 1箱 = 10公斤
      "splits": [                   // 分裂项
        {
          "quantity": 5,            // 1箱 = 5包
          "unitId": 3
        }
      ]
    }
  ],
  "enableAttributes": true,         // 启用属性
  "attributeCombinations": [        // 属性组合
    {
      "id": 0,
      "name": "红色 / L码",
      "purchasePrice": 50,
      "wholesalePrice": 80,
      "retailPrice": 100,
      "barcode": "6901234567890",
      "enabled": true
    },
    {
      "id": 1,
      "name": "蓝色 / L码",
      "purchasePrice": 50,
      "wholesalePrice": 80,
      "retailPrice": 100,
      "barcode": "6901234567891",
      "enabled": true
    }
  ]
}
```

## API 接口

### 新增商品
- **URL**: `/products`
- **Method**: `POST`
- **数据**: 上述完整提交数据

### 编辑商品
- **URL**: `/products/{id}`
- **Method**: `PUT`
- **数据**: 上述完整提交数据

## 数据验证规则

1. **门店 (storeIds)**: 必须至少选择一个门店
2. **仓库 (warehouseId)**: 必须选择一个仓库
3. **分类 (categoryId)**: 必须选择一个分类
4. **商品名称 (name)**: 必须填写
5. **单位 (unitId)**: 必须选择一个基础单位

## 注意事项

1. 仓库选择会根据选择的门店自动筛选
2. 分类选择会根据选择的仓库自动筛选
3. 单位换算中的 fromUnitId 不能等于基础单位 unitId
4. 属性组合通过笛卡尔积自动生成，用户只需选择属性和选项
5. 价格字段支持小数点后两位
