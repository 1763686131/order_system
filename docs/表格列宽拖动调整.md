# 表格列宽拖动调整

`v-resizable-columns` 已在 `src/main.js` 中全局注册，其它页面无需单独导入即可使用。

该指令适用于原生 HTML 表格，要求表头只有一行、没有合并单元格，并且 `colgroup` 中每个可见列都有一个对应的 `<col>`。表格应放在支持横向滚动的容器中，并使用 `table-layout: fixed`。

## 使用示例

```vue
<template>
  <div class="table-scroll">
    <table v-resizable-columns="{ storageKey: 'product-list', minWidth: 40 }">
      <colgroup>
        <col style="width: 160px" />
        <col style="width: 120px" />
        <col style="width: 100px" />
      </colgroup>
      <thead>
        <tr>
          <th data-column-key="name" data-min-width="100">商品名称</th>
          <th data-column-key="code">商品编码</th>
          <th data-column-key="actions" data-resizable="false">操作</th>
        </tr>
      </thead>
      <tbody><!-- 业务数据行 --></tbody>
    </table>
  </div>
</template>

<style scoped>
.table-scroll { overflow-x: auto; }
table { width: 100%; table-layout: fixed; border-collapse: collapse; }
</style>
```

## 配置参数

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| `enabled` | `true` | 设置为 `false` 时禁用拖动调整，并恢复默认样式。 |
| `storageKey` | `''` | 当前表格在 `localStorage` 中保存列宽的独立标识。不设置时，列宽仅在当前表格挂载期间有效。 |
| `minWidth` | `40` | 最小列宽，单位为像素。 |
| `maxWidth` | 不限制 | 最大列宽，单位为像素。 |
| `resizeMode` | `'expand'` | `'expand'` 会改变表格总宽度；`'fit'` 保持表格总宽度不变，由最右侧其它可调整列补偿宽度变化。 |
| `onResize` | 无 | 拖动结束、键盘调整或恢复默认宽度后触发，参数为 `{ key, index, width, widths }`。 |

直接使用 `v-resizable-columns` 且不传值，可启用不持久化的列宽调整。

只需要设置保存标识时，可以简写为 `v-resizable-columns="'product-list'"`。不同用途或布局的表格应使用不同的 `storageKey`，避免列宽设置相互影响。

## 单列配置

可以在 `<th>` 或 `<col>` 上设置以下属性：

| 属性 | 说明 |
| --- | --- |
| `data-column-key` | 列的稳定标识，用于匹配保存的列宽。未设置时使用规范化后的表头文字。 |
| `data-min-width` | 当前列的最小宽度，优先于全局 `minWidth`。 |
| `data-max-width` | 当前列的最大宽度，优先于全局 `maxWidth`。 |
| `data-resizable="false"` | 禁止调整当前列，也不让该列参与固定总宽度模式的宽度补偿。 |

存在重复表头、表头多语言切换或文字随数据变化时，建议显式设置 `data-column-key`，保证列宽能正确匹配。

条件隐藏的列重新显示时，会恢复之前保存的宽度。指令只保存调整过的列宽；固定总宽度模式下，参与补偿的列宽也会保存，不会保存业务数据。

## 固定总宽度

`BusinessDocumentForm` 已启用 `resizeMode: 'fit'`：

- 拖宽一列时，压缩最右侧其它可调整列的空间，表格右边界保持不动。
- 补偿列缩到最小宽度后，停止继续拖宽。
- 调整最后一列时，由它前面的可调整列补偿宽度变化。
- 恢复保存的列宽时，会按当前布局的默认总宽度重新适配，包括旧版扩展模式保存的设置。
- 保留表格原本的横向滚动，不会因为拖宽列而继续增加表格总宽度。

其它页面需要相同行为时，传入对应配置即可：

```vue
<table v-resizable-columns="{ storageKey: 'product-list', resizeMode: 'fit' }">
  <!-- 表头、列定义及业务数据 -->
</table>
```

## 交互与限制

- 拖动表头右边界，调整对应列的宽度。
- 双击表头右边界，恢复该列默认宽度；固定总宽度模式下，仍受补偿列的最小和最大宽度限制。
- 聚焦调整边界后，按左右方向键每次调整 `10px`；配合 `Shift` 每次调整 `1px`；按 `Home` 恢复默认宽度。
- 在禁用的 `fieldset` 和只读表单中，仍可调整列宽。
- 缺少匹配的 `colgroup` 或存在合并表头时，不启用拖动调整；支持数据行、合计行中的合并单元格。
- 表格卸载时会清理事件监听、尺寸观察和临时样式。
- 浏览器存储不可用或保存失败时，仍可正常调整列宽。
