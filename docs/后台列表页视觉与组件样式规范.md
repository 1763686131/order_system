# 后台列表页视觉与组件样式规范

> 参考实现：`src/views/admin/orders/UnifiedOrderList.vue`
>
> 适用范围：Vue 3 后台管理页面、筛选列表、数据表格、居中详情弹窗和信息弹窗
> 更新日期：2026-09-10

这份规范用于复用 `UnifiedOrderList` 形成的紧凑型后台数据界面风格。实现新页面时优先复用这里的设计 token、尺寸和交互模式，再根据业务字段做内容适配。不要直接复制订单页的业务条件、接口逻辑或订单字段。

## 1. 风格定位

- **产品气质**：克制、清晰、偏工具化，服务于高频录入、筛选、核对和批量操作。
- **信息密度**：在不牺牲可读性的前提下保持紧凑，优先展示结构化数据，避免大面积装饰和营销式留白。
- **视觉层次**：页面浅灰底，内容使用白色面板承载；层次主要由边框、间距、字号和少量阴影建立。
- **主色语义**：墨绿色用于主操作、当前筛选、链接和焦点；红色只表示危险操作或异常；状态色必须有明确语义。
- **形状语言**：面板使用小圆角，标签使用胶囊形；不要把普通按钮、表格或页面区块做成大圆角卡片。
- **本地资源**：图标使用项目内联 SVG 或本地资源，不引入 CDN、远程字体或在线图标库。

## 2. 设计 Token

新组件建议在根容器上定义局部变量，避免直接散落颜色值。下表是当前视觉基线：

| Token | 值 | 用途 |
| --- | --- | --- |
| `--accent` | `#0f9f78` | 主按钮、激活 tab、链接、焦点 |
| `--accent-rgb` | `15, 159, 120` | 透明 hover、selected 和 focus 光晕 |
| `--accent-dark` | `#08745a` | 主色 hover、深色文字 |
| `--accent-soft` | `#e9f8f3` | 次按钮 hover、浅色提示背景 |
| `--accent-border` | `#a9e5d2` | 主色相关边框 |
| `--page-bg` | `#f4f7f8` | 页面背景 |
| `--panel-bg` | `#ffffff` | 面板、表格页脚、弹窗头尾 |
| `--border` | `#e2e8f0` | 普通分隔线和面板边框 |
| `--border-strong` | `#cbd5e1` | 输入框、按钮、分页控件边框 |
| `--text` | `#172033` | 主文字、标题 |
| `--text-secondary` | `#596579` | 标签、次级信息、日期 |
| `--text-muted` | `#8a96a8` | 占位、辅助说明、空态副文案 |

建议保留以下基础约定：

```css
.page-root {
  --accent: #0f9f78;
  --accent-rgb: 15, 159, 120;
  --accent-dark: #08745a;
  --accent-soft: #e9f8f3;
  --accent-border: #a9e5d2;
  --page-bg: #f4f7f8;
  --panel-bg: #fff;
  --border: #e2e8f0;
  --border-strong: #cbd5e1;
  --text: #172033;
  --text-secondary: #596579;
  --text-muted: #8a96a8;
  color: var(--text);
  background: var(--page-bg);
  font-size: 14px;
}
```

### 尺寸和间距

- 页面基准字号 `14px`，标签/表头通常 `11px-13px`，小标题 `14px`，页面或弹窗标题不超过 `18px`。
- 常规输入框、按钮高度 `38px`，刷新等纯图标按钮使用 `36px`。
- 普通控件圆角 `5px`，面板圆角 `7px`，分段控件外壳 `8px`，状态标签使用 `999px`。
- 间距以 `4/6/7/8/10/11/12/14/15/16/18/20px` 为主，避免随意引入新的间距级别。
- 边框默认 `1px`；阴影仅用于面板和浮层，保持低透明度。
- 金额、数量、页码、日期等可比较数字使用 `font-variant-numeric: tabular-nums`；金额同时使用千分位和固定精度。

## 3. 页面结构

推荐的列表页结构如下，业务页面可按需省略某一段，但层级顺序尽量保持一致：

```text
页面根容器
├─ 搜索面板 search-panel
│  └─ 搜索网格 search-grid
├─ 记录面板 records-panel
│  ├─ 工具栏 records-toolbar
│  │  ├─ 分组筛选 toolbar-filters
│  │  └─ 操作区 toolbar-actions
│  ├─ 横向滚动容器 table-scroll
│  │  └─ 固定布局数据表
│  └─ 表格页脚 table-footer / pagination
└─ Teleport 到 body 的居中详情弹窗
```

### 搜索面板

- 使用白色面板、`1px` 边框、`7px` 圆角、轻阴影，默认 `padding: 18px 20px`。
- 内部使用 CSS Grid，桌面基线可采用：

  ```css
  grid-template-columns: minmax(200px, 1fr) minmax(280px, 1.45fr)
    minmax(160px, 1fr) auto;
  gap: 14px;
  align-items: end;
  ```

- 每个字段采用“标签在上、控件在下”的垂直布局，标签 `12px / 600`，字段间距 `7px`。
- 输入框、选择框统一高 `38px`、内边距 `0 11px`、圆角 `5px`；搜索图标放在左侧时，输入内容左内边距约 `35px`。
- 日期范围使用三列网格，中间用“至”等短分隔文本，不要用多个独立卡片表达日期区间。
- 复杂筛选下拉菜单应相对触发器定位，菜单有白底、边框、轻阴影和最大高度；选项支持键盘和复选框，点击外部关闭。

### 记录面板和工具栏

- 记录面板与搜索面板保持同一套白底、边框、圆角和阴影，通常 `margin-top: 14px`。
- 工具栏采用左右布局：左侧筛选，右侧刷新、导出、新建、批量操作；最小高度约 `62px`，内边距 `11px 16px`，间距 `20px`。
- 分类、状态等互斥筛选使用“浅灰外壳 + 分段按钮”，比普通下拉更适合高频切换。
- 筛选组外壳：`#f1f5f9` 背景、`padding: 4px`、`gap: 6px`、`border-radius: 8px`，可以配合轻微内阴影。
- 分段按钮高 `36px`、水平内边距约 `16px`、圆角 `6px`；激活态使用主色背景和白字，hover 使用主色低透明背景。
- 计数徽章最小宽高 `20px`，数字 `11px / 700`；激活态使用白色低透明背景。
- 选中数量提示可用 `margin-left: auto` 推到筛选区右侧，数字使用主色深色并略放大。

## 4. 按钮和控件

### 通用按钮

```css
.button {
  display: inline-flex;
  height: 38px;
  align-items: center;
  justify-content: center;
  gap: 7px;
  padding: 0 15px;
  border: 1px solid transparent;
  border-radius: 5px;
  font-size: 13px;
  font-weight: 600;
  white-space: nowrap;
  transition: background .18s ease, border-color .18s ease,
    color .18s ease, box-shadow .18s ease;
}
```

- **主按钮**：主色背景和边框，白字；hover 切换为 `--accent-dark`，保留轻微主色阴影。
- **次按钮/导出按钮**：白底、`--border-strong` 或中性灰边框；hover 变为 `--accent-soft`、主色深文字。
- **危险按钮**：没有可操作对象时灰底灰字并禁用；有选中对象后才显示红色背景（如 `#ef4444`），hover 变为更深红色。
- **图标按钮**：刷新、关闭、分页箭头等使用固定尺寸按钮，不用文字包裹熟悉的单一操作；不熟悉的图标必须提供 `title` 或可见辅助文本。
- 所有禁用控件使用 `cursor: not-allowed` 和约 `0.45` 的透明度，但仍保持布局尺寸不变。
- 图标优先使用本地内联 SVG，统一线性风格：`fill: none; stroke: currentColor; stroke-linecap: round; stroke-linejoin: round; stroke-width: 1.8`。

### 焦点和交互

```css
button:focus-visible,
input:focus-visible,
select:focus-visible,
.record-row:focus-visible {
  outline: 2px solid var(--accent);
  outline-offset: 2px;
}
```

输入框获得焦点时同时使用主色边框和约 `3px` 的低透明光晕。不要仅依赖颜色变化表达焦点或选中状态。

## 5. 数据表格规范

- 表格放在 `overflow-x: auto` 的容器中，优先保证列宽和信息可读性，不在窄屏强行压缩所有列。
- 使用 `table-layout: fixed`，业务列较多时设置合理的 `min-width`；订单页的参考值为 `1320px`，其他页面按列数重新计算。
- 表头高约 `45px`，浅灰背景 `#f8fafc`，字号 `12px / 650`，底部有分隔线。
- 数据行高约 `57px`，单元格内边距 `9px 12px`，底部使用 `#edf1f5` 细线；最后一行可取消底边框。
- 文本列默认 `overflow: hidden; text-overflow: ellipsis; white-space: nowrap`；完整内容通过 `title` 或详情弹窗查看。
- 数字列右对齐并使用 `tabular-nums`，操作列居中；复选框列固定宽度、垂直居中。
- 订单号、文档编号等主标识可以使用主色深色粗体按钮并带右箭头，hover 下划线；不要把每个普通单元格都做成链接。
- 行可以整体点击打开详情，但复选框、行内按钮、标签等嵌套交互必须阻止冒泡，避免误打开详情。
- hover 和 selected 使用主色透明底：hover 约 `0.18`，selected 约 `0.12`；不要使用高饱和整行纯色。

### 列宽建议

下列值来自订单列表，可作为同类后台列表的起点，最终按字段长度和页面总宽度调整：

| 列类型 | 建议宽度 |
| --- | ---: |
| 复选框 | `50px` |
| 文档/订单编号 | `140px` |
| 日期 | `110px` |
| 客户/主体 | `140px` |
| 联系人 | `100px` |
| 电话 | `120px` |
| 地址 | `140px` |
| 商品/摘要 | `150px` |
| 数字列 | `100px`，右对齐 |
| 操作列 | `100px`，居中 |

## 6. 标签、状态和反馈

### 状态标签

状态标签统一使用胶囊形、最小高度约 `25px`、内边距 `3px 9px`、字号 `12px / 650`，可在左侧放 `6px` 圆点。颜色按语义使用，不按页面模块随意变色：

| 语义 | 文字色 | 背景色 | 示例 |
| --- | --- | --- | --- |
| 成功/已完成 | `#13734f` | `#eaf8f1` | 已出库、已发布 |
| 已审核/信息完成 | `#16647a` | `#e7f5f8` | 已完成、已审核 |
| 待处理/进行中 | `#a4510b` | `#fff3df` | 待审核、待处理 |
| 取消/不可用 | `#b4232f` | `#f1f2f4` | 已取消 |

物流方式、回单等辅助标签可以沿用胶囊形但降低字号；可点击标签应通过蓝色文字、hover 背景或下划线明确可交互。

### 顶部通知（Toast / Notice）

顶部通知用于反馈已经完成、正在处理或失败的轻量结果。它不阻断当前页面操作，也不承载二次确认；需要用户做决定、填写内容或查看完整原因时，应使用确认弹窗或详情弹窗。

#### 使用原则

- 通知固定在视口顶部，不参与页面布局，不得推动列表、工具栏或表单发生位移。
- 默认水平居中，距离视口顶部 `20px`；移动端左右至少保留 `16px` 安全间距。
- 同一时刻最多显示一条主通知。连续触发时优先更新当前通知内容，避免通知堆叠遮挡页面。
- 成功和普通信息默认 `3s` 后自动关闭；警告和错误默认 `5s` 后关闭。包含重试、撤销等关键操作时可以保持显示，直到用户主动关闭。
- 文案应先说结论，再补充必要原因，例如“订单保存成功”“上传失败：文件格式不支持”。不在通知中展示长段落、表单或复杂操作流程。
- 通知关闭后不应改变当前筛选条件、滚动位置或已填写表单；刷新列表等后续动作应由业务逻辑显式触发。

#### 动效与组件示例

通知进入和离开只使用轻微的透明度与垂直位移动画，不使用缩放或横向滑入，避免顶部内容产生夸张跳动：

```css
.notice-enter-active,
.notice-leave-active {
  transition: opacity 0.18s ease, transform 0.18s ease;
}

.notice-enter-from,
.notice-leave-to {
  opacity: 0;
  transform: translate(-50%, -8px);
}

@media (prefers-reduced-motion: reduce) {
  .notice-enter-active,
  .notice-leave-active {
    transition: none;
  }
}
```

推荐的 Vue 结构如下：

```vue
<Transition name="notice">
  <div
    v-if="notice.visible"
    class="page-notice success"
    role="status"
    aria-live="polite"
  >
    <span class="page-notice-icon" aria-hidden="true">✓</span>
    <span class="page-notice-text">{{ notice.message }}</span>
    <button
      class="page-notice-close"
      type="button"
      aria-label="关闭通知"
      @click="notice.visible = false"
    >
      ×
    </button>
  </div>
</Transition>
```

- 成功和普通信息使用 `role="status"`、`aria-live="polite"`，不要打断用户当前阅读。
- 警告和错误使用 `role="alert"`；如果包含关闭按钮，关闭按钮必须有明确的 `aria-label`。
- 图标属于装饰时设置 `aria-hidden="true"`，真实状态必须由文案表达。
- 通知的 `z-index` 默认高于页面内容和下拉菜单，但低于确认弹窗和全屏详情弹窗；若通知由弹窗内部触发，应在弹窗关闭后再显示。
- `max-width`、换行和移动端安全间距必须保留，不能因为长订单号、文件名或错误信息撑破视口。

```css
@media (max-width: 780px) {
  .page-notice {
    top: 12px;
    min-width: 0;
    max-width: calc(100vw - 32px);
  }
}
```

### 加载和空状态

- 加载状态优先保留表头和行高，显示约 `5` 行 skeleton，避免页面高度跳动。
- skeleton 条宽约容器的 `78%`、高 `10px`、圆角 `3px`，使用浅灰渐变和 `1.25s` 线性 shimmer 动画。
- 空表格使用单独的空态行，建议高度约 `290px`，内容居中：`48px` 浅灰圆形图标、主文案 `14px`、辅助文案 `12px`。
- 空态文案应说明当前结果为空以及下一步动作，例如“调整筛选条件后重新查询”，不要只显示“暂无数据”。
- 成功、警告、失败反馈使用页面已有通知机制；不要在表格中大量堆叠颜色鲜艳的提示框。

## 7. 分页和页脚

- 表格页脚独立使用白底和顶部边框，最小高度约 `58px`，内边距 `10px 16px`，左右两端对齐。
- 总记录数使用 `12px` 辅助文字，数字加粗并使用 `tabular-nums`。
- 分页控件间距约 `8px`；页大小选择器约 `103x32px`，前后按钮约 `31x31px`；页码区域保留最小宽度，避免页码变化造成抖动。
- 禁用分页按钮保留可见边框并降低透明度，不改变尺寸。

## 8. 居中详情弹窗

适合承载一条记录的完整信息、明细表和后续操作。建议通过 `Teleport` 挂载到 `body`，避免被父级 `overflow` 或层叠上下文裁剪。

- 遮罩覆盖整个视口，背景使用 `rgba(15, 23, 42, .42)`，可加 `1px` blur。
- 弹窗在视口水平、垂直居中，宽度使用 `min(960px, calc(100vw - 48px))`，最大高度使用 `min(880px, calc(100vh - 48px))`。
- 弹窗背景使用浅灰 `#f4f7f9`，头部和底部为白色，主体独立滚动；移动端（`<=780px`）占满视口。
- 头部最小高度约 `78px`，标题图标 `40x40px`，主标题 `18px`；关闭按钮固定 `34x34px`。
- 主体内使用白色信息卡：边框 `#dfe5ec`、圆角 `7px`；元信息默认两列网格，摘要数据可使用三列 summary strip。
- 明细表继续遵循固定布局、横向滚动、数字右对齐的表格规范；合计行使用浅灰底和较粗的上边框。
- 底部操作区最小高度约 `68px`，白底、顶部边框；关闭按钮在左侧，当前业务操作放在右侧并允许换行。
- 动画建议：遮罩透明度约 `0.2s ease`，弹窗使用轻微上移和缩放进入，不使用侧滑抽屉动画。

### 短流程弹窗

用于运费、审核、录入等独立短流程。弹窗需有遮罩、明确标题、关闭按钮、最大宽度和移动端约束；费用/信息类弹窗可参考 `500px` 宽、`90vw` 最大宽度、`24px` 内边距。新弹窗优先复用详情弹窗的边框、文字和按钮体系，避免出现完全不同的圆角、阴影和颜色。

### 确认和提示弹窗

用于清空、删除、关闭等需要二次确认的操作，以及保存成功、操作失败等结果反馈。统一使用自定义弹窗组件，**禁止**使用浏览器原生 `alert()`、`confirm()` 或 `prompt()`。

**参考实现**：`src/views/admin/orders/OrderForm.vue` 中的清空确认弹窗、关闭确认弹窗和成功/错误提示弹窗。

## 9. 响应式规则

```css
@media (max-width: 1280px) {
  .search-grid {
    grid-template-columns: repeat(2, minmax(0, 1fr));
  }
}

@media (max-width: 780px) {
  .search-grid {
    grid-template-columns: 1fr;
  }

  .detail-modal {
    width: 100vw;

  }

```

- `1280px` 以下搜索区由四列降为两列，避免标签和输入框挤压。
- `780px` 以下降为单列，工具栏允许换行，详情弹窗占满屏幕。
- 数据表格保留横向滚动，不为了适配手机而缩到无法阅读；必要时给关键列设置最小宽度。
- 所有按钮、标签、页码和动态文本必须有稳定尺寸或最小尺寸，加载、hover 和状态变化不能导致布局跳动。

## 10. 无障碍和交互检查

- 页面区块使用语义化的 `section`、`header`、`footer`；筛选区提供 `aria-label`。
- 分段筛选使用 `role="tablist"`，选项状态需要可被键盘和辅助技术识别。
- 详情弹窗使用 `role="dialog"` 和 `aria-modal="true"`；遮罩点击关闭时保留显式关闭按钮。
- 装饰性 SVG 设置 `aria-hidden="true"`；图标按钮必须有 `title` 或可访问名称。
- 可点击表行使用 `tabindex="0"`，支持 Enter 打开详情；焦点轮廓不能被移除。
- 复选框、行操作和下拉菜单处理事件冒泡，保证点击控件只执行当前操作。
- 下拉菜单在打开后支持点击外部关闭；加载时刷新按钮禁用并可显示旋转动画。
- 颜色不是唯一状态信号：状态标签保留文字，危险操作不能只靠红色区分。

## 11. 与业务无关的实现边界

以下内容属于 `UnifiedOrderList` 的订单业务，不应写入其他组件的通用样式：

- `finance` / `logistics` 模式及其条件渲染。
- 订单、门店、收货人、物流单号、回单、运费等字段名称和 API。
- 门店颜色通过 `--store-bg-color` 设置整行背景的规则。
- 订单状态、订单号、商品明细、金额格式化和具体截断长度。
- 批量删除、出库、录入物流、复制单号等业务动作。
- 旧订单字段兼容逻辑，以及临时的旧版 `expand-modal` / `order-detail-modal` 结构。

复用时只保留“结构模式”和“视觉 token”，将业务字段、操作权限和数据格式放回各自页面或 composable。可复用的弹窗应迁移到 `src/components/`，页面专属样式留在组件的 `<style scoped>` 中；确实跨页面复用的 token 再沉淀到 `src/assets/styles/`。
