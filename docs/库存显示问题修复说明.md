# 库存显示问题修复说明

## 🐛 问题描述

**现象**：在订单录入页面选择商品后，"当前库存"列显示为空或0，但实际上商品有库存。

**原因**：
1. 库存数据存储在 `products_db.json` 的 `inventory` 对象中
2. 前端调用的 `/api/products` 接口只返回商品基本信息，不包含库存
3. 需要调用 `/api/products/inventory` 接口才能获取带库存的数据

---

## ✅ 修复方案

### 修改的文件
- `src/views/admin/orders/OrderForm.vue`

### 修改内容

**修改前**：
```javascript
const loadProducts = async () => {
  const response = await request({ url: '/products', method: 'GET' })
  products.value = response
}
```

**修改后**：
```javascript
const loadProducts = async () => {
  // 使用 /products/inventory 接口，返回的数据包含库存信息
  const response = await request({ url: '/products/inventory', method: 'GET' })
  products.value = response
}
```

## 📊 数据结构说明

### products_db.json 结构

```json
{
  "products": [
    {
      "id": 1,
      "name": "粘钢胶",
      "specification": "40kg/组",
      "price": 50
      // 注意：这里没有 stock 字段
    }
  ],
  "inventory": {
    "1": {  // 商品ID作为key
      "stock": 4000,  // 库存在这里
      "minStock": 0,
      "maxStock": 0,
      "updatedAt": "2026-09-04 14:47:41"
    }
  }
}
```

### 两个接口的区别

| 接口 | 返回数据 | 是否包含库存 |
|------|----------|--------------|
| `GET /api/products` | 只返回 products 数组 | ❌ 不包含 |
| `GET /api/products/inventory` | 合并 products + inventory | ✅ 包含 |

### /api/products/inventory 返回示例

```json
[
  {
    "id": 1,
    "name": "粘钢胶",
    "specification": "40kg/组",
    "price": 50,
    "stock": 4000,  // ← 自动合并的库存字段
    "minStock": 0,
    "maxStock": 0,
    "inventoryUpdatedAt": "2026-09-04 14:47:41"
  }
]
```

## 🔍 后端接口实现（参考）

后端 `backend/routes/products.py` 中的 `get_inventory()` 函数：

```python
@products_bp.route('/inventory', methods=['GET'])
def get_inventory():
    """获取库存列表（带库存信息的商品数据）"""
    data = read_products()
    products = data.get('products', [])
    inventory_list = data.get('inventory', {})
    
    result = []
    for product in products:
        product_id = str(product['id'])
        # 获取该商品的库存信息
        inventory_info = inventory_list.get(product_id, {
            'stock': 0,
            'minStock': 0,
            'maxStock': 0
        })
        
        # 合并商品信息和库存信息
        result.append({
            **product,
            'stock': inventory_info.get('stock', 0),
            'minStock': inventory_info.get('minStock', 0),
            'maxStock': inventory_info.get('maxStock', 0)
        })
    
    return jsonify(result)
```

## 📝 相关说明

### 为什么库存要单独存储？

这是一种数据库设计模式：
1. **商品基本信息**：商品ID、名称、规格等（不常变）
2. **库存信息**：库存数量、最小/最大库存等（经常变）

分开存储的好处：
- ✅ 更新库存时不影响商品基本信息
- ✅ 可以更灵活地管理库存历史
- ✅ 减少数据冗余

### 其他使用库存的地方

如果你的项目中还有其他地方需要显示商品库存，也要确保：
1. 调用 `/api/products/inventory` 接口
2. 或者从返回的数据中获取 `stock` 字段

## ⚠️ 注意事项

1. **后端库存扣减**：后端保存订单时会自动扣减库存，这部分逻辑已经正确实现

2. **库存检查**：如果商品在 `inventory` 中没有记录，默认库存为 0

3. **数据迁移**：如果你的旧商品数据中 `stock` 直接存在 `products` 对象里，需要迁移到 `inventory` 对象
