# 打印模板功能进度与后续计划

更新时间：2026年9月14日

## 一、项目目标

实现进销存系统的可视化打印模板设计功能，支持销售出库单、采购入库单、退货单等业务单据的自定义打印。

### 打印方案选择

针对三联打印机（241mm × 140mm）的打印需求，推荐使用 **C-Lodop 打印控件**方案：

**为什么选择 C-Lodop？**
- ✅ 支持精确控制打印位置，适配三联针式打印机
- ✅ 支持套打（在预印单据上打印）
- ✅ 支持多联打印、连续打印
- ✅ 提供打印预览和调试功能
- ✅ 可精确控制页边距、偏移量

**浏览器原生打印的局限：**
- ❌ 无法精确控制纸张位置
- ❌ 不支持套打
- ❌ 页边距控制不准确
- ❌ 不适合针式打印机场景

### 当前设计原则

- 使用可视化设计器编辑打印模板
- 模板数据存储在数据库中，支持多用户共享
- 支持按业务类型（销售/采购/退货等）分类管理模板
- 明细表格根据实际数据动态生成行数
- 后续接入 C-Lodop 实现真实打印

### 6. 表格变量使用方式

**推荐配置：**

在设计器的表格元素中：
```text
数据变量：@items
列定义变量：留空
表脚数据变量：留空
```

**列手动设计示例：**

| 列名 | 变量绑定 |
|------|----------|
| 序号 | @index |
| 商品名称 | @goodsName |
| 规格 | @spec |
| 单位 | @unit |
| 数量 | @quantity |
| 单价 | @price |
| 金额 | @amount |

**工作原理：**
1. `@items` 决定表格生成多少行（根据商品数量）
2. 每列的变量决定该列显示什么内容
3. 不需要的列可以不创建（比如不显示单价、金额）

**表脚处理：**
- 表脚可以显示”合计”文字
- 表脚单元格可以绑定合计变量（如 `@totalQuantity`, `@totalAmount`）
- 预览时会自动补充表脚数据

**注意事项：**
- ⚠️ `@items` 只能放在”数据变量”，不能放在”列定义变量”
- ⚠️ “列定义变量”用于动态生成列配置，与明细数据无关
- ⚠️ 如果表格不绑定 `@items`，则只显示固定的设计行数

### 三联单打印参考

三联单（241mm × 140mm）打印要点：

1. **纸张设置**
   ```javascript
   LODOP.SET_PRINT_PAGESIZE(0, 2410, 1400, “”)
   // 参数：打印方向(0=纵向), 宽度(0.1mm), 高度(0.1mm), 纸张名
   ```

2. **页边距控制**
   ```javascript
   LODOP.SET_PRINT_STYLE(“FontSize”, 10)
   LODOP.SET_PRINT_STYLE(“Bold”, 0)
   ```

3. **套打模式**
   - 如果使用预印单据，需要精确定位每个字段的打印位置
   - 建议提供”打印测试页”功能，用于校准偏移

4. **连续打印**
   ```javascript
   // 批量打印多张单据
   for (let i = 0; i < orders.length; i++) {
     LODOP.PRINT_INIT(“”)
     // ... 添加内容
     if (i === orders.length - 1) {
       LODOP.PRINT() // 最后一张才真正打印
     }
   }
   ```
