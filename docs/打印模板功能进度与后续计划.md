# 打印模板功能进度与后续计划

更新时间：2026年9月13日

## 一、当前目标

实现销售订单的可视化打印模板设计，纸张尺寸暂定为 `210mm × 140mm`，用于三联单场景。

当前设计原则：

- 一张三联单只打印一份，不是连续打印三份。
- 模板由前端可视化设计器编辑。
- 订单数据由 `OrderForm.vue` 传给打印预览。
- 明细表格支持手动选择列，同时根据订单商品数量动态重复行。
- 后续再接入浏览器打印和 C-Lodop 打印。

### 4. 订单变量

当前已提供订单基础变量：

- 门店、客户、仓库
- 单据编号、单据日期
- 联系人、联系电话、地址
- 业务员、制单人、订单备注
- 含税开关、税率
- 合计件数、合计数量、合计金额
- 应收、实收、欠款等金额变量

商品明细变量包括：

- `index`：序号
- `productId`：商品 ID
- `goodsName`：商品名称
- `spec`：规格型号
- `unit`：单位
- `warehouseName`：仓库
- `packages`：件数/包装数
- `quantity`：数量
- `price`：单价
- `taxRate`：税率
- `taxIncludedPrice`：含税单价
- `amount`：金额
- `totalAmount`：含税金额
- `remark`：商品备注

### 5. 表格变量使用方式

推荐的表格配置方式：

```text
列定义变量：留空
数据变量：@items
表脚数据变量：留空
```

`@items` 只负责根据商品数量动态生成明细行，不会决定表格显示哪些列。

列可以完全手动设计，例如：

```text
序号       商品名称       规格       单位       数量
@index     @goodsName     @spec      @unit      @quantity
```

如果不需要单价、金额列，不创建对应列即可。

注意：

- `@items` 不能放在“列定义变量”中。
- “列定义变量”要求的是列配置数组，不是商品明细数组。
- 如果完全不使用数组变量，表格只能显示固定设计行，不能根据商品数量动态增加行。

### 6. 表脚处理

已处理自定义表格默认没有表脚数据的问题：

- 打开“显示表脚”时自动补充默认表脚行。
- 默认表脚支持合计文字。
- 数量、件数、金额可以绑定订单合计变量。
- 预览时也会补充表脚。

## 三、当前已知限制

### 1. 模板还没有存入数据库

目前保存位置是浏览器 `localStorage`，存在以下问题：

- 换浏览器后模板消失。
- 换电脑后模板消失。
- 清理浏览器缓存后模板消失。
- 多个用户之间无法共享模板。
- 后端无法统一管理模板版本。

### 2. 还没有接入真实打印

当前只有网页预览，尚未完成：

- 浏览器打印
- C-Lodop 打印
- 打印机选择
- 打印份数和打印方向设置
- 打印偏移校准
- 无边距打印处理

### 3. 模板权限还没有完善

后续需要区分：

- 谁可以新增模板
- 谁可以编辑模板
- 谁可以删除模板
- 谁可以设置默认模板
- 普通员工是否只能使用模板

### 4. 模板版本管理还没有完善

当前保存会直接覆盖原模板，暂时没有：

- 版本号
- 历史版本
- 恢复历史版本
- 发布/草稿状态
- 编辑冲突提示

## 四、明天优先继续的工作

### P0：将模板从 localStorage 迁移到数据库

建议新增数据库表 `print_templates`。

建议字段：

```text
id
name
business_type
paper_type
page_width
page_height
enabled
is_default
design_json
version
created_by
updated_by
created_at
updated_at
```

其中：

- `design_json` 保存可视化设计器生成的完整 JSON。
- `business_type` 区分销售、采购、退货等业务。
- `is_default` 表示当前业务类型的默认模板。
- `version` 为后续模板版本和并发控制准备。

建议接口：

```text
GET    /print-templates
GET    /print-templates/:id
POST   /print-templates
PUT    /print-templates/:id
DELETE /print-templates/:id
PUT    /print-templates/:id/default
```

前端完成数据库接口后：

- `PrintTemplate.vue` 不再直接读写 `localStorage`。
- `OrderForm.vue` 从接口加载可用销售模板。
- 保留一次性 localStorage 迁移逻辑，把旧模板上传到数据库。

### P1：完成真实打印适配

建议抽象打印适配器：

```text
BrowserPrintAdapter
CLodopPrintAdapter
```

打印入口统一为：

```text
printTemplate(template, orderData, options)
```

根据用户选择调用不同打印方式：

- 网页打印：浏览器 `window.print()`
- C-Lodop：调用本地 C-Lodop 服务

### P1：完善 210mm × 140mm 打印校准

- 表格跨页时表头和表脚是否重复
- 不同打印机的缩放比例
