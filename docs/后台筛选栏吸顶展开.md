# 后台筛选栏吸顶展开

`Admin.vue` 负责滚动监听，以及顶部栏下方的居中展开按钮。
页面通过 `useAdminStickyPanel` 注册筛选区域，无需自行添加吸顶按钮或滚动监听。
目前销售订单和物流订单已接入。

向下滚动后，筛选栏自动收起；点击向下箭头展开。展开时隐藏按钮，
鼠标滚轮再次滚动或内容区滚动时自动收起，返回顶部则恢复原有布局。
滚轮在筛选栏内部滚动也会收起；按钮使用绝对定位，不占页面布局空间。

## 页面接入

保留筛选栏的外层占位区域和内层内容区域，分别绑定元素引用和返回的样式：

```vue
<template>
  <div ref="filterShell" :style="placeholderStyle">
    <section
      id="example-filter-panel"
      ref="filterContent"
      :style="contentStyle"
    >
      <!-- 原有的筛选表单和操作按钮 -->
    </section>
  </div>
  <!-- 原有的列表区域 -->
</template>

<script setup>
import { ref } from 'vue'
import { useAdminStickyPanel } from '@/composables/useAdminStickyPanel'

const filterShell = ref(null)
const filterContent = ref(null)
const { pinned, placeholderStyle, contentStyle } = useAdminStickyPanel(
  filterShell,
  filterContent,
  { id: 'example-filter-panel', label: '筛选栏' }
)
</script>
```

`id` 应与筛选区域的 HTML `id` 一致；`label` 用于按钮的提示和无障碍名称。
`pinned` 表示已进入吸顶状态，可用于隐藏页面原有的移动端展开按钮。
外层保留原来的高度，内层在展开时固定于顶部栏下方，切换不会改变列表的位置。
页面卸载时会自动清理注册；未接入的页面不会显示父级按钮。

## 可选配置

| 配置 | 用途 |
| --- | --- |
| `threshold` | 向下滚动多少像素后自动收起，默认 `24` |
| `onPin` | 进入吸顶时保存页面自身的显示状态 |
| `onExpand` | 展开时显示完整筛选内容 |
| `onCollapse` | 收起时关闭页面内的下拉菜单 |
| `onRestore` | 返回顶部或注销时恢复原有显示状态 |

每个后台页面注册一个筛选区域。外层需要覆盖完整的原始筛选栏高度，
内层的宽度随内容区调整；样式中不要用 `transform` 或 `contain`
把内层固定定位限制在页面自身的容器中。
离开 `Admin.vue` 布局时，筛选内容保持普通页面布局。
