# 商品明细弹窗调试指南

## 问题描述
弹窗无法正常打开，不显示订单编号

## 🔍 调试步骤

### 步骤 1：检查浏览器控制台

1. **打开浏览器开发者工具**
   - 按 `F12` 或 `Ctrl + Shift + I`
   - 切换到 **Console（控制台）** 标签

2. **刷新页面**
   - 按 `Ctrl + F5` 强制刷新
   - 清除缓存并重新加载

3. **点击 📋 图标**
   - 观察控制台输出
   - 应该能看到以下日志：
     ```
     打开订单明细弹窗 {id: xxx, order_number: "ZG20260904NEW", ...}
     订单编号: ZG20260904NEW
     商品明细: [{...}, {...}]
     弹窗状态: true
     ```

4. **检查是否有错误**
   - 如果控制台有红色错误信息，记录下来
   - 常见错误：
     - `Cannot read property 'order_number' of undefined`
     - `showOrderDetail is not defined`
     - `orderDetailVisible is not defined`

---

### 步骤 2：检查是否看到 📋 图标

**问题 A：看不到 📋 图标**

**可能原因**：
1. 订单不是新格式（没有 `order_goods` 字段）
2. `isNewOrder()` 函数判断有误

**解决方法**：
```javascript
// 在浏览器控制台执行
// 查看订单数据
console.log(paginatedOrders.value)

// 检查第一个订单是否有 order_goods
console.log(paginatedOrders.value[0]?.order_goods)
```

---

### 步骤 3：检查弹窗是否存在于 DOM 中

1. **打开开发者工具的 Elements（元素）标签**
2. **点击 📋 图标**
3. **按 `Ctrl + F` 搜索**：`order-detail-modal`
4. **检查结果**：
   - ✅ 找到了：说明弹窗已渲染，可能是样式问题
   - ❌ 找不到：说明 `orderDetailVisible` 没有变为 `true`

---

### 步骤 4：检查弹窗样式

**如果弹窗存在但看不见，可能是样式问题**

在浏览器控制台执行：
```javascript
// 检查弹窗元素
const modal = document.querySelector('.order-detail-modal')
console.log('弹窗元素:', modal)
console.log('弹窗样式:', window.getComputedStyle(modal))

// 检查遮罩层
const overlay = document.querySelector('.expand-modal-overlay')
console.log('遮罩层:', overlay)
console.log('遮罩层样式:', window.getComputedStyle(overlay))
```

## 🐛 常见问题及解决方法

### 问题 1：点击 📋 没反应

**原因**：点击事件没有正确绑定

**检查方法**：
```javascript
// 在控制台执行
document.querySelectorAll('.detail-btn').forEach(btn => {
  console.log('找到按钮:', btn)
})
```

**解决方法**：
- 刷新浏览器（Ctrl + F5）
- 检查 Vue 是否正确初始化

---

### 问题 2：弹窗打开但不显示内容

**原因**：`currentDetailOrder.value` 为 `null` 或数据不完整

**检查方法**：
```javascript
// 点击 📋 后，在控制台执行
console.log('当前订单数据:', currentDetailOrder.value)
console.log('订单编号:', currentDetailOrder.value?.order_number)
```

**解决方法**：
- 检查订单数据是否包含 `order_number` 字段
- 检查数据是否正确传递

---

### 问题 3：显示订单编号为 "-"

**原因**：
1. 订单数据中没有 `order_number` 字段
2. `order_number` 的值为 `null` 或空字符串

**检查方法**：
```bash
# 在命令行执行
grep -A 5 "order_goods" e:/order_system/data/orders_db.json | grep "order_number"
```

**解决方法**：
- 确保保存订单时生成了 `order_number`
- 检查后端保存逻辑是否正确

---

### 问题 4：弹窗样式错乱

**原因**：CSS 样式未正确加载

**检查方法**：
```javascript
// 检查样式是否存在
const styles = document.querySelectorAll('style')
let found = false
styles.forEach(style => {
  if (style.textContent.includes('order-detail-modal')) {
    found = true
    console.log('找到弹窗样式')
  }
})
if (!found) {
  console.error('弹窗样式未加载')
}
```

**解决方法**：
- 强制刷新浏览器（Ctrl + Shift + R）
- 清除浏览器缓存
