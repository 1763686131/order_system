## 🐛 常见问题排查

### 问题 1：看不到 📋 图标

**原因**：
- 订单不是新格式（没有 `order_goods` 字段）
- 浏览器缓存未刷新

**解决方法**：
1. 检查订单数据是否包含 `order_goods` 数组
2. 按 `Ctrl + F5` 强制刷新浏览器
3. 清除浏览器缓存

### 问题 2：点击 📋 图标没反应

**原因**：
- JavaScript 错误
- 弹窗函数未正确绑定

**解决方法**：
1. 按 `F12` 打开浏览器控制台
2. 查看是否有错误信息
3. 检查 `showOrderDetail` 函数是否定义

### 问题 3：商品明细弹窗显示不全

**原因**：
- 订单数据缺少字段
- 样式未正确加载

**解决方法**：
1. 检查订单数据是否完整
2. 刷新浏览器
3. 检查 CSS 是否加载

### 问题 4：搜索不到新订单

**原因**：
- 订单编号字段为空
- 搜索逻辑未生效

**解决方法**：
1. 检查订单是否有 `order_number` 字段
2. 检查搜索函数是否正确修改
3. 刷新浏览器
